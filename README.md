## 🚀 Current Projects

### 1. Daily Maintenance Automation
- **Location**: `.github/workflows/daily-cleanup.yml`
- **Description**: GitHub Actions workflow that runs automated cleanup and monitoring tasks
- **Tools**: GitHub Actions, Docker, Python

### 2. Docker Cleanup Utility
- **Location**: `scripts/cleanup-docker.sh`
- **Description**: Bash script to clean up unused Docker resources
- **Usage**: `./cleanup-docker.sh [--all]`

### 3. Log Monitor
- **Location**: `scripts/log-monitor.py`
- **Description**: Python script to analyze logs for errors and generate reports
- **Usage**: `python3 log-monitor.py [logfile]`
